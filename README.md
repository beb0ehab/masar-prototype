# مسار · Masar — Recruitment Desk (Prototype)

نموذج تفاعلي (Prototype) لنظام إدارة استقدام وتوظيف العمالة المنزلية: ملفات العاملات، الإجراءات والمستندات، المصاريف، الحسابات، التقارير والصلاحيات.

> **هذا نموذج واجهات فقط.** البيانات كلها وهمية ومولّدة تلقائياً، ولا يوجد Backend أو قاعدة بيانات — أي إضافة أو تعديل يختفي عند تحديث الصفحة. الهدف هو الاتفاق على شكل النظام ودورة العمل قبل التطوير الفعلي.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو:

```bash
node server.js
```

ثم افتح <http://localhost:4173>.

## ما الذي يعرضه النموذج

| القسم | ما يمكن تجربته |
|---|---|
| لوحة التحكم | أعداد العاملات حسب المرحلة، أين تقف الملفات الآن، التنبيهات (إجراء متأخر، صلاحية منتهية، جواز قارب على الانتهاء)، والصورة المالية للشهر |
| العاملات | بحث بالاسم / الرقم التعريفي / رقم الجواز، فلترة بالحالة، تسجيل عاملة جديدة |
| ملف العاملة | مسار الرحلة من مانيلا إلى الرياض عبر 8 إجراءات، تغيير حالة كل إجراء، رفع أو تصوير المستندات، حساب العاملة، سجل التعديلات |
| مصاريف العاملات | كل مصروف مربوط بعاملة، بعملته وطريقة دفعه وإيصاله، مع إجمالي تلقائي |
| مصاريف المكتب | مصاريف شهرية / سنوية / لمرة واحدة، مع تاريخ الاستحقاق والدفع |
| الحسابات | أرباح وخسائر شهرية وسنوية، مدفوعات العملاء، أسعار الصرف (USD / PHP / EGP) |
| التقارير | تقرير شهري أو سنوي، تصدير Excel (CSV) و PDF (طباعة) |
| المستخدمون | مصفوفة الصلاحيات وسجل النشاط |

**جرّب الصلاحيات:** من القائمة أعلى الصفحة «معاينة النظام بصلاحية» بدّل بين Admin / Accountant / HR / Viewer لترى كيف تتغير القوائم والأزرار. زر اللغة يبدّل بين العربية والإنجليزية.

## ملاحظات على النموذج

- تاريخ «اليوم» مثبّت على 2026-11-10 حتى تظهر نفس البيانات في كل مرة.
- كل الأرقام المالية (التكاليف، الرسوم، أسعار الصرف) افتراضية للعرض فقط.
- التقارير تُحوَّل إلى الدولار بآخر سعر صرف مسجّل؛ في النظام الفعلي كل عملية تُحفظ بسعر صرف يوم تسجيلها.

## التنفيذ الفعلي المقترح

React (واجهة) · Laravel (Backend) · MySQL · سيرفر سحابي خاص، مع نسخ احتياطي دوري واستيراد بيانات Excel الحالية.
